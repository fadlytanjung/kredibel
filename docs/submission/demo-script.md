# Demo video script

The video's script, timings and shot list are generated with the video itself:
[`demo-video/script.md`](demo-video/script.md) (from `tools/video/narration.json`, see
[`README.md`](README.md#the-video)). It runs 3 to 4 minutes, as the challenge requires, and is recorded
on production with the public demo account.
